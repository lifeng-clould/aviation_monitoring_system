# 机坪牵引作业监管平台

## 项目简介
本项目面向机场机坪牵引作业监管场景，围绕“计划编排、执行回传、风险联动、数据治理、责任追溯”构建了一套区块链协同监管平台。平台以牵引案例为核心对象，将航班计划、牵引任务、ADS-B 轨迹、车辆 GPS、授权审批和审计记录统一到同一监管闭环中，用于支撑多主体协同、过程留痕、风险识别、隐私保护与链上审计。

平台当前采用标准前后端壳层：
- 后端：FastAPI
- 前端：React + Vite + Ant Design
- 数据处理：Pandas
- 地图与轨迹：Mapbox / React Map GL
- 运行方式：后端可直接托管前端构建产物

## 核心能力
### 1. 多源数据接入与事件重构
- 接入航班主表、牵引任务表、ADS-B 飞机轨迹、拖车 GPS 轨迹
- 按时间窗口、机位邻近、时空交互强度进行案例匹配
- 将分散数据提升为统一的“单次牵引案例”对象

### 2. 轨迹追溯与证据还原
- 地图回放飞机与牵引车轨迹
- 展示关键阶段：开始牵引、脱离牵引、进入跑道、起飞离场、轨迹结尾
- 提供事件定位、候选排序、证据评分、关键时间节点留痕

### 3. 风险指挥与规则联动
- 识别净距不足、超速、双重异常等风险
- 在联动总台展示实时告警流与处置链路
- 通过智能合约式规则触发风险通道写入与处置回传

### 4. 数据治理与隐私保护
- 提供资产登记、导入校验、授权审批、监管台账、数据预览等工作面
- 支持脱敏视图与原始字段授权访问并行
- 以最小必要原则控制跨主体共享边界

### 5. 区块链存证与审计追溯
- 对计划、执行、风险、监管等关键节点分通道留痕
- 固化授权审批、撤销、调用与归档动作
- 支撑责任追溯、案例复盘与监管审计

## 快速部署
### 1. 安装 Python 依赖
在项目根目录执行：

```powershell
python -m pip install -r requirements.txt
```

如果你使用虚拟环境，可先激活虚拟环境再安装。

### 2. 安装前端依赖
```powershell
cd front-end
npm install
cd ..
```

### 3. 构建前端
```powershell
cd front-end
npm run build
cd ..
```

### 4. 启动后端并托管前端
```powershell
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8002
```

启动后访问：
- 首页：[http://127.0.0.1:8002/](http://127.0.0.1:8002/)
- 展示区：[http://127.0.0.1:8002/showcase?view=overview](http://127.0.0.1:8002/showcase?view=overview)
- 健康检查：[http://127.0.0.1:8002/api/health](http://127.0.0.1:8002/api/health)

## 角色与协同主体
平台围绕四类主体组织工作面：
- 机场运控：计划签发、放行协同、全局节奏控制
- 地服公司：牵引执行、证据回传、异常补录
- 航空公司：影响评估、责任复核、授权申请
- 监管审计：审批、抽检、归档、追责

## 区块链作用定位
平台中的区块链并不是单纯做“数据上链”，而是承担以下职责：
- 固化关键监管节点
- 建立跨主体统一证据底账
- 留痕授权审批与访问动作
- 支撑风险事件自动写入与审计归档
- 为责任追溯和案例复盘提供稳定依据

## 常见问题
### 1. 页面打开后显示骨架屏较久
平台启动时会读取并匹配大量轨迹数据，首次加载会比普通管理系统慢一些。可先查看健康接口：

```powershell
Invoke-WebRequest -UseBasicParsing http://127.0.0.1:8002/api/health
```

### 2. 展示区或地图样式没有更新
浏览器可能缓存了旧的前端资源，建议强制刷新：
- Windows：`Ctrl + F5`

### 3. 前端构建时出现大 chunk 警告
这属于当前依赖规模带来的构建提示，不会阻止页面运行，但后续可继续做分包优化。
